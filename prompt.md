# The commission

> bubble bobble is a great idea!  it doesnt have to be so neon, it can be
> high quality arcade. use the same harsh critic loop.

Twelfth game in the series, and the first to leave the wireframe behind.
Same method — one owner builds a single-file tribute, deterministic
`?shot=` captures, four harsh sub-agent critics (composition, game-feel,
HUD, and a Bubble-Bobble-fidelity judge), honest scores, publish — but
the look is arcade now: chunky saturated blocks, dragons with faces,
iridescent bubbles, fruit, and a CRT finish. Still no assets: every
pixel and every sound is generated from code.

The proof harness's next species: **rescues as theorems** — a bot that
must empty every room of the keep, controls that must fail, and a
mechanism proof for every rule from the bubble's arc to the hurry-up
ghost. Plus the mutation gate that NEOTRIS introduced, now a permanent
part of the method.
